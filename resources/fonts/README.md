# Schriften für das Einbrennen der Untertitel (libass)

TTF-Dateien, die FFmpeg/libass beim Export über `fontsdir` lädt. Alle unter SIL Open Font License 1.1.

| Datei | Familie im ASS | Quelle |
|---|---|---|
| Anton-Regular.ttf | `Anton` | Google Fonts / @fontsource/anton (latin) |
| Montserrat-Black.ttf | `Montserrat Black` | @fontsource/montserrat 900 (latin) |
| Montserrat-ExtraBold.ttf | `Montserrat ExtraBold` | @fontsource/montserrat 800 (latin) |

Eigene Kunden-Schriften: TTF/OTF hier ablegen und im Preset den Familiennamen eintragen.
